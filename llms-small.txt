# distillers quick reference

distillers is an offline Python document-distillation engine. The stdlib core parses fixed web-text-mirror banners, extracts source-anchored units, renders Markdown and JSON, and deduplicates text. Optional ollama-client supplies embeddings.

Start with docs/wiki/README.md, docs/DEVELOPMENT.md and docs/TESTING.md.

Verify:
python3 -m py_compile distill_offline.py
python3 -m unittest discover -s tests -v
python3 scripts/generate_repo_docs.py --check

Core: distill_offline.py. Frozen: split_master.py, categorize_topics.py, clean_*.py.
Configuration: OLLAMA_HOST, OLLAMA_HOSTS, DISTILL_EMBED_MODEL. Default host is localhost:11434.
Keep mirror page source_anchor values intact. Use --no-semantic for offline bulk.
